# MCN Boot 官网与文档设计提案

三套可交互的视觉方向，用于选择官网与文档的升级风格。每套包括首页，以及快速开始、依赖管理、自动配置三篇文档效果稿。

| 方案 | 设计方向 | 官网布局 | 文档体验 |
| --- | --- | --- | --- |
| A · 深林工作台 | 深林色、薄荷绿、工程工作台 | 左侧产品叙事，右侧依赖编辑器；下接能力与组件架构 | 深色阅读、清晰步骤、三栏导航 |
| B · 暖白技术刊物 | 暖白、陶土橙、刊物式排版 | 衬线标题与分层基础图；横向代码示例与编号章节 | 暖白纸感、细分隔线、留白与正文层次 |
| C · 午夜架构图谱 | 墨蓝、电紫、架构可视化 | 居中标题与模块连接图；强调组件组合关系 | 墨蓝阅读、紫色定位、模块化代码与提示 |

## 本地查看

不需要安装新依赖。在仓库根目录执行：

```powershell
python -m http.server 4190 --bind 127.0.0.1 --directory design-preview
```

打开 `http://127.0.0.1:4190/`。也可以直接用浏览器打开本目录的 `index.html`；代码复制需要浏览器允许剪贴板操作，推荐使用 localhost。

- `?concept=forest&view=home`：A 首页；`?concept=forest&view=docs`：A 文档。
- `?concept=paper&view=home`：B 首页；`?concept=paper&view=docs`：B 文档。
- `?concept=orbit&view=home`：C 首页；`?concept=orbit&view=docs`：C 文档。
- 顶部切换方案及页面；首页按钮、文档导航、页内锚点、前后篇、代码复制和预览搜索均可操作。
- `Ctrl / ⌘ K` 打开搜索，`Esc` 关闭。搜索范围为这三篇效果稿，不是当前正式文档全文。

## 内容依据与边界

内容参考根目录 `README.adoc`、`pom.xml` 和现有文档导航；编辑器与架构图是说明性设计，不会运行 Maven 或连接服务。4.1.0 是当前仓库版本，不代表已在 Maven 仓库正式发布。没有引入第三方字体、CDN、图片、分析服务或其他依赖。

本目录独立于正式 VitePress 页面和构建，保留三套效果稿供对比。已选定 B 方案，正式官网与文档主题的实现位于 `docs/.vitepress/theme/`；在仓库根目录运行 `npm run docs:dev` 查看实际网站。

效果稿只检索三篇示例，正式站使用 VitePress 的全站本地搜索。正式教程已按当前源码更新，关键示例位于 `docs/examples/`，可使用 `mvn -Pdocs-check test` 编译并验证。外部服务与部署集成仍需在应用环境中验证。发布状态以正式站的交付说明为准。
